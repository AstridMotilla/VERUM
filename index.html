How it works. This proves a statement the way a course does — from principles, not a truth table. It rewrites the statement step by step with logical equivalences (eliminate → and ↔, De Morgan, distribute, simplify) until only ⊤ remains; reaching ⊤ from the laws alone is the proof. Put the same statement in the formula tab and the truth table lands on the same verdict a different way.

Easter egg These aren't proofs or truth tables. They show that the same Boolean operators, applied over positions or over time, draw fractals. It's here to connect the dots, not part of the logic core.

Combine across bits

How it works. Write the row number i and column number j in binary. At each bit position the formula judges the pair (a = i's bit, b = j's bit); the answers are combined down to one filled/empty. Splitting off the top bit makes each quadrant a shrunk copy of the whole — that recursion is the fractal. ¬(a ∧ b) with ∧ blanks the quadrant where both top bits are 1, giving the gasket's three-copies-and-a-hole.

Rule — variables l, c, r (left, centre, right)

insert
try

How it works. The top row is a single filled cell. Each row below is built from the one above: every cell becomes the formula applied to its left, centre and right neighbour (l, c, r). Time runs downward. l ⊕ r is Rule 90 — from one seed it draws the Sierpiński triangle, because XOR of neighbours copies and cancels the same way the bitwise version does.
